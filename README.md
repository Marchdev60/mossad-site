# Site sobre o Mossad

Projeto desenvolvido para praticar desenvolvimento web utilizando HTML e CSS.

## Sobre o projeto

Este projeto consiste em um site informativo sobre o Mossad, apresentando informações sobre sua história, atuação e curiosidades.

## Tecnologias utilizadas

- HTML5
- CSS3

## Objetivo

O objetivo deste projeto é aplicar conhecimentos de desenvolvimento web e criar uma página organizada e responsiva.
